# TeamFit Android

웹 프로토타입의 핵심 사용자 흐름을 Jetpack Compose로 구현한 Android MVP입니다. 실제 인증은 `https://teamfitv12.vercel.app`의 Vercel API와 Supabase Auth를 사용합니다.

## 실행 방법

1. Android Studio에서 Open을 누릅니다.
2. 이 ZIP을 푼 폴더의 `TeamFit-Android` 폴더를 선택합니다.
3. Gradle JDK는 JDK 17 또는 21을 선택합니다.
4. Android SDK Platform 36을 설치하고 Gradle Sync를 실행합니다.
5. Android 8.0(API 26) 이상의 에뮬레이터나 기기를 선택한 뒤 Run을 누릅니다.

IntelliJ IDEA에서는 Android 및 Kotlin 플러그인과 Android SDK를 먼저 활성화한 뒤 같은 폴더를 Gradle 프로젝트로 열 수 있습니다. Android 앱 실행과 에뮬레이터 사용은 Android Studio를 권장합니다.

## 구현 기능

- 팀장·팀원 구분 없는 통합 회원가입 및 로그인
- 실제 이메일 인증 링크 발송 및 인증 완료 계정 로그인
- 로그인 후 팀장/팀원 활동 모드 선택과 전환
- 관리자 계정의 실제 가입자·이메일 인증 현황 조회
- 실제 공모전 목록 및 공모전 상세정보( 실제 공공데이터 이용)
- 팀장 모집글 작성 및 지원자 관리
- 팀원 모집 조건 비교 및 지원
- 공개 역량 프로필과 비공개 개인정보 분리
- 추천 질문이 포함된 추가 질문 채팅
- 팀장의 최종 합류 요청 및 팀원의 최종 수락/거절
- 모집 인원이 모두 수락한 뒤 연락처 공개
- 마이페이지 개인정보 및 역량 프로필 편집
  

## 회원가입·관리자 확인

1. Android 앱에서 이름, 이메일, 연락처, 비밀번호를 입력해 회원가입합니다.
2. 이메일의 인증 링크를 눌러 인증을 완료합니다. 인증 완료 페이지는 웹 브라우저에서 열립니다.
3. Android 앱으로 돌아와 이메일과 비밀번호로 로그인합니다.
4. Vercel의 `ADMIN_EMAILS`에 등록된 이메일이라면 활동 모드 화면과 상단 메뉴에서 `가입자 관리`를 열 수 있습니다.

`SUPABASE_SERVICE_ROLE_KEY`는 Android 앱에 포함하지 않습니다. 가입자 조회는 관리자 로그인 토큰을 Vercel API가 검증한 뒤 서버에서만 처리합니다.

## 현재 MVP 저장 방식

계정과 관리자 목록은 Supabase에 연결됩니다. 공모전, 모집글, 지원, 메시지와 팀 선택 상태는 아직 앱 프로세스 안에서 동작하는 시연용 데이터입니다. 다음 단계에서는 이 데이터도 서버 데이터베이스에 연결하고 인증 토큰 갱신, 영구 로그인, 푸시 알림을 추가해야 합니다.
